# Validation — Becoming v2

2026-10-15: **30 automated tests passed on Python 3.14**. They use controlled fixtures and no live model/network. The repository's GitHub Actions workflow runs the suite on Python 3.11 and 3.14 when the update is published.

Tests cover v1 browsing/URL/robots/DNS/HTTP controls plus exact quotation validation, malformed schema and non-finite scores, rejected arbitrary model URLs and identity fields, source-linked beliefs, journal/questions/interests, reflection-driven link selection, idempotent reflection, revalidation at the memory boundary, v1 save migration, local-only schema-based inference, and main-content extraction with nested containers.

The smaller model initially failed to reproduce an exact quotation from a long saved page; the claim was rejected and no journal or belief was recorded. The final interface instead asks it to select a source-passage index, attaches the corresponding actual text in code, and revalidates that passage at the memory boundary. A new test checks that bounded source windows preserve contiguous source text. This binds citations to observed text but cannot guarantee that the interpretation is entailed.

A real **local Gemma 3 4B** call interpreted an unseen short forest-ecology fixture: it paraphrased the source, returned three source-exact claims, proposed questions about drought and forest ecosystems, and selected the provided drought link. A longer live-page reflection timed out, retaining the page and reporting the error. The shipping CPU-conscious configuration defaults to Gemma 3 1B, limits each list to one item, uses a shorter context and requests two CPU threads. Model output was saved locally outside the repository. This demonstrates a working model connection and plausible interpretation for one passage, not generalized comprehension accuracy.

The earlier live web test supplied only Python.org as a starting URL; the agent followed links to two conference pages. Existing reading memories are preserved for the v2 live observer. v2 uses explicit provenance and separates pretrained knowledge from personal reading history. All source claims remain unverified. Matching quotations do not establish whether a paraphrase is entailed, whether a source is correct, or whether two sources are independent.

No consciousness, human IQ, autobiographical identity discovery, autonomous fact-checking, or human-equivalence percentage is established. Generated reflections can be mistaken. Local CPU inference is slower than the original word learner. Live websites may refuse bot access, time out, change, or require JavaScript.

Final live check: **Gemma 3 1B with numbered source passages** successfully reflected on the saved PyCon Panama page in the actual observer, recorded a source-linked claim and public journal entry, developed an interest in Python programming, and revised its self-description from three recorded reading experiences and one reflection. The model inferred generic conference activities beyond the explicit source and returned an unusable uncertainty string. The observer therefore labels interpretations as unverified and displays a warning when uncertainty text is unusable. This is a functional comprehension/reflection demonstration with observed quality limitations, not an accuracy benchmark. No test reading history is included in Git.
